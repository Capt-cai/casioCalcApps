# Recovered version index

These archives were created during the P0 version-control task from existing
verified local snapshots. They are NOT historic Git commits, and their archive
creation does not backdate work or confer acceptance on M5-M8. All original source
manifests and user-binary hashes are retained. Current source lives normally in
Git; archives provide recovery of earlier stages without rewriting history.

`index.json` lists Phase1,M2A,M2B,originalM3,M4,M5,M6,custom-width,M7,M8. Original
M2A-M4 acceptance is explicit user-reported hardware acceptance; no agent-operated
measurements are inferred. M5/M6 hardware deferred;custom-width/M7/M8 pending.

Verify: `python3 scripts/verify-version-archives.py`.
Restore one stage into a NEW empty destination:

```sh
python3 scripts/verify-version-archives.py --restore m4 --destination /tmp/ecen21-m4-recovery
```

The restored `build-source/` is the original self-contained source tree,with
`apps/`, `common/` and Boolean core as applicable. `artifacts/ECEN21.g3a` is the
original user binary (Phase1 uses Logic.g3a). Source manifests and per-member
hashes are checked before restoring. No current working files are overwritten.
Use the pinned Docker toolchain in docs/TOOLCHAIN.md to build that restored source
root; historical reproduction helpers/records are evidence and may contain old
local paths. Full emulator/compiler installs/caches are intentionally excluded.

Each archive includes build sources,engineering user/test artifacts,relevant
reports/logs/UI references and available reproduction records. Compiled host test
executables,dSYM,pyc,Docker/vendor trees and unrelated files are excluded. M8 HDL
case caches are regenerated by the versioned Python testbench,not archived.

The byte-identical legacy M4 accepted bundle remains locally at
`.phase1/checkpoints/M4-accepted.tar.gz` with its original SHA256 recorded in the
index. It contains Finder .DS_Store metadata and is not uploaded. The curated
m4.tar.gz retains every77source-manifest input and the identical accepted binary.
Historical records inside archives are immutable and keep their original statuses;
root project records provide later acceptance/deferral corrections.
