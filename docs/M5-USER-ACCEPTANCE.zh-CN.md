# M5 实机验收指南：计数器与顺序电路设计求解器

当前状态：M4 已由你确认在真实 Casio fx-CG50 上验收通过并关闭；M5 工程验证已完成；你随后明确要求“开始M6吧 实机验收后面一起做”，因此 M5 实机验收延期而非通过，M6 已批准。统一验收请使用 M6 最新程序并参照 M6 指南，本指南的 M5 功能步骤保留。电脑和模拟器的结果不能替代实体按键、安装与退出测试。

## 1. 本阶段实现什么

现在可以输入状态循环，自动得到状态表、触发器激励表、每根输入端的精确 SOP/POS 化简、K-Map 分组、实际状态轨迹、未使用状态的恢复／陷阱分析，以及可照着画电路的连接说明。还可以输入已有的触发器方程，反过来求电路状态及输出。

支持范围：2 或 3 个状态位；可选一个控制输入 E；每个状态位可分别使用 D、T、JK、SR；全部触发器共用上升沿或下降沿时钟。可输入最多两根输出 Z0/Z1 的方程。状态循环每支至少两个不同状态，最多覆盖全部状态；表达式最多 79 个字符；E 时间序列最多 32 步。M3 仍保持原来的 8/16/32 位功能，没有重写或扩展。

这不是画波形或模拟真实器件延迟的工具，也不支持级联时钟、Latch、异步复位、Verilog 或超过三位的计数器设计。初始状态只是分析起点和接线说明中的初始化要求，不代表程序自动设计了硬件复位电路。

术语：Q 是当前状态，Q+ 是下一状态；SOP/POS 是两种等价化简形式；Required 是题目要求，Actual 是化简后的真实电路会产生的值；X 表示该输入取 0 或 1 都合法；! 表示下一状态未定义。状态二进制按 Q2、Q1、Q0 从左到右排列，两位时是 Q1、Q0。

未使用状态有三种明确策略：RETURN 返回指定状态（默认 0）；HOLD 原地停留；DC 允许化简器自由选择。DC 不是“必定安全恢复”，程序会展示具体补全后的行为。SOP 与 POS 在 DC 状态上的补全可能不同，请按页面选定的形式查看整个电路。

## 2. 哪些检查已通过，哪些仍未验证

已通过的工程检查：

- 电脑和模拟器中实际运行的计算器代码，六组结果一致：早期控制器 218 项、布尔模型 6,516 项、数值模型 20,779 项、单触发器 3,849 项、M5 求解模型 2,216 项、连接说明 128,986 项。
- 新增主机检查 916,124 项，覆盖 5,408 个设计模型；包括全部两位状态映射与混合触发器组合，以及规定的三位／控制输入例题和抽样设计。不是穷尽所有三位电路。
- 连接说明中的门电路文字会被独立读回执行，逐行验证输出；受控计数器检查一颗三输入 XOR 和一颗 NOT 的接线要求。
- 数值运算既有检查 2,359,296 项、精确布尔化简 153,092 个算例、模拟器基础检查 5/5 通过。
- 实际按键脚本覆盖 100 张 M5 页面与 20 项页面关系检查；原有布尔、数值和 M4 工具页面与验收版本保持一致。代表性的表格、K-Map、长输入、错误、记录和多页连接已人工查看。

仍待实机确认：USB 安装、真实按键手感、文字可读性、返回系统及长时间稳定性；未测量真实计算器上的耗时或内存／栈峰值。M4 的实机验收不自动代表 M5 实机验收通过。

## 4. 按顺序进行实机测试

以下步骤从刚启动的首页开始。数字直接按，不使用 ALPHA。多数示例按 OPTN 后选数字，再按 F6 计算；选示例会明确替换当前 M5 题目。其他工具的数据仍保留。

常用键：F1 设置；F2 依次切换状态表／激励表／输出表；F3 方程；F4 K-Map；F5 更多页面；F6 求解。结果页的左右键选择输入端，上下键翻页；K-Map 上下键换分组，EXE 看分组解释。加号／减号切换 SOP/POS。设置页上下键选字段，EXE 改设置或打开完整文字编辑；编辑时 AC 清空、DEL 删除、左右移动光标、EXE 保存、EXIT 取消。

### A. T 计数器及完整设计结果

1. 首页按 **4、F6**。默认三位 T 计数器为 `0→3→5→7→0`。第一页应看到：000→011、001→000、010→000、011→101、100→000、101→111。Required 与 Actual 相同。按 DOWN，第二页应为 110→000、111→000；UP 返回。
2. 按 **F2** 看激励表，先选中 T2；按 RIGHT 两次选 T0。000 行 T0 的 Required 为 1，Actual 为 1。Required 为 X 时，Actual 允许选择 0 或 1，不是错误。
3. 按 **F3** 看 T0 方程。映射应为 A=Q2、B=Q1、C=Q0；SOP 可显示 `A'B'+ABC`，2 组、5 个文字。等价但不同的最优写法也可以。按加号／减号切换形式，页面必须明确显示 SOP 或 POS。
4. 按 **F4**。应有 Gray 顺序的 K-Map、各格行号与选中分组；EXE 看覆盖行和分组得到的项／子句，上下键能访问各组。再 EXE 回图。
5. 按 **F5、1** 看轨迹，应为 **0、3、5、7、0**，Prefix 0、Period 4。Prefix 是进入循环前的步数，Period 是循环长度。
6. 按 **F5、3** 看恢复分析。未使用的 1、2、4、6 应能先回 0 再进入循环；不得误报为安全性未经分析的“自动恢复”。上下键可以看全部起点。
7. 按 **F5、2** 看接线。应有三个 T 触发器、同一 RISE 时钟、初始状态、常量／反馈、门节点和各 T 输入的最终连接。上下键可访问所有页。`N5=AND(...)` 代表一个中间门节点；`FF0.T <- N5` 表示 Q0 对应触发器的 T 引脚接到 N5。

### B. 手动输入、错误修复及未使用状态

8. 按 **OPTN、1** 回默认题设置页，选中应为 Problem mode。按 **DOWN 10 次、EXE** 打开 Cycle E=0。按 AC，输入 **03570**，EXE 保存，F6 求解。状态表应与步骤 1 一致。也可用小数点键插入逗号，输入 `0,3,5,7,0`。
9. 按 **F1、EXE、AC**，改成 **0305**，EXE 保存、F6 求解。应显示 Repeated internal cycle state，字符位置 3。按 EXE 返回，再按 F3，必须显示 No current result，不能继续展示旧答案。
10. 按 **F1、EXE、AC**，输入 **03570、EXE、F6**，恢复正常。之后打开同一编辑器，AC 后连续输入 0 超过 31 次，应显示容量已满提示；按 EXIT 取消，再 F2，旧的有效解仍在。取消不能偷偷覆盖原题。
11. 按 **OPTN、1**，从设置第一页按 **DOWN 4 次、EXE**，将 Unused states 从 RETURN 改为 HOLD，F6 求解。未使用状态例如 001 应保持 001。按 F5、3，未使用状态应显示 TRAP，即不会进入指定循环的陷阱。
12. 按 **F1、EXE** 将 HOLD 改为 DC，F6 求解。未使用行的 Required 应显示 DC，Actual 给出具体补全；F5、3 必须有“无恢复保证”的提示。分别切换 SOP/POS 查看，给定循环仍必须正确，即使未使用行的补全不同。

### C. JK 与混合触发器设计

13. 按 **OPTN、2、F6、F5、1**。应得到 **0→1→4→7→3→5→0**，Period 6。DOWN 可看第二页末尾回到 0。状态表中未使用的 2、6 应回 0。各 J/K 方程、K-Map、接线均可访问。
14. 按 **OPTN、3、F6、F5、1**。混合题应是 Q2=D、Q1=T、Q0=JK，轨迹 **0→3→1→2→5→4→7→6→0**，Period 8；DOWN 看后半段。
15. 按 **F2、F2** 进入激励表。左右依次查看 D2、T1、J0、K0：000→011 这一行的 Required 应分别为 **0、1、1、X**。最后两行也应可翻页访问；111→110 对应 **1、0、X、1**。

### D. 控制输入 E 与四变量上限

16. 按 **OPTN、4、F6、F5、1**，固定 E=0 时应为 **0→2→3→1→0**。
17. 按 **F1** 回设置；当前选中回到示例的第一个字段。按 **DOWN 7 次、EXE、F6、F5、1**，Fixed trace E 改为 1，应为 **0→1→3→2→0**。
18. 按 **F5、2** 查看连接。上下翻页，应能找到一颗三输入 XOR，输入来自 Q1、Q0、E；其结果接 Q0 的 T，引出一颗 NOT 后接 Q1 的 T。示例中可显示 `N5=XOR(N2,N3,N4)`、`N6=NOT(N5)`、`FF0.T <- N5`、`FF1.T <- N6`。不应只给一大组与或式而缺少题目要求的 XOR/NOT 实现。
19. 按 **OPTN、4、UP、EXE**，从首字段向上绕到最后的 E timeline。AC 后输入 **0101、EXE、F6、F5、1**。轨迹应为 **0→2→0→2→0**，并显示时间序列结束，不凭重复的 Q 就宣称完整控制系统进入循环。
20. 按 **OPTN、6、F6**。这是三位加 E 的四变量边界例子。上下翻页应有 **16 行、3 页**，E=0 和 E=1 都有数据。F4 图应为 4×4；方程、分组、轨迹和全部连接页可查看，不能仅算前 8 行。

### E. 输入方程反向分析与输出

21. 按 **OPTN、5、F6**。映射 A=Q1、B=Q0。原方程在设置中保留：T1=`B+!A`，J0=`!B*A`，K0=`!B+A`，Z0=`B`。
22. 状态表应为 **00→10、01→11、10→11、11→00**。从状态表按 F2 两次看输出表：Z0 依次为 **0、1、0、1**，Z1 为减号（未指定），不是凭空输出 0。F5、1 的轨迹为 **0→2→3→0**，Period 3。
23. 按 **OPTN、5** 回新示例设置，从第一个字段 **DOWN 9 次、EXE**，应打开 Input T1。AC 后输入 **B+**：按 log、加号，再 EXE、F6。应给出语法错误，不显示旧结果。按 EXE 返回，EXE 再编辑；AC 后按 **log、加号、除号、X/θ/T**，输入 `B+!A`，EXE、F6 应修复为步骤 22 的状态表。
24. 按 **OPTN、7、F6、F5、1**。两个 D 触发器相互交换，初始状态 01，必须是 **01→10→01**。若得到 00 或 11，说明错误地逐个更新，不能验收通过。F1 设置中的 Clock edge 改为 FALL 后重新 F6，轨迹仍应交换，接线中应明确写 FALL。
25. 按 **OPTN、8、F6**。SR 的 S=R=1，状态表下一状态必须为红色 **!**。F5、1 显示从起点进入 undefined 并停止，不得编造正常二进制下一状态；F5、3 也应标出 INVALID。

### F. 切换工具、帮助和退出

26. 按 **OPTN、3、F6、F5、1**，记住混合题的轨迹。EXIT 回首页，1 进入布尔工具、EXE 计算；EXIT 回首页，2 进入数值工具、EXE 计算。首次打开的默认数值为 255+1=0、Carry=1。若你在同次运行中改过旧工具，应保留你改后的数据。
27. EXIT 回首页，3 打开原单触发器工具，应仍可操作；EXIT、4 返回 M5，原混合题和轨迹必须保留。F5、5 看帮助，任意键返回；OPTN 后按 EXE 取消选例，题目也不得改变。
28. 在 M5 内 EXIT 应返回首页；首页再 EXIT 应返回计算器系统。重新启动后为全新默认数据，没有永久保存上一题的承诺。

## 5. 验收标准

以下项目都满足，才能确认 M5 通过：四类题型能接受自定义输入而非只能查看示例；规定状态序列和输出正确；所有触发器同步读取旧状态；表格、激励、SOP/POS、K-Map／分组、轨迹、恢复和连接可完整查看；控制 E 两支及 16 行边界正确；未使用策略和 SR 未定义行为清晰；错误后没有旧答案，修复后恢复；旧工具不受影响；页面可读、无异常退出、能返回系统。

本阶段不要求 M6 的时序图或 M8 的 Verilog。通过后请明确回复“M5 实机验收通过”。验收通过不等于批准 M6，下一阶段仍需另行授权。
