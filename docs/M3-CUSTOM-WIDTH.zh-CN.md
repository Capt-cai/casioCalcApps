# Binary 自定义位宽更新：用户验收指南

这是你明确要求的 M3 小范围更新，不是 M7。M5、M6 实机验证继续暂缓；本次新增功能的实机验收尚未通过，M7 尚未批准。

## 1. 现在能做什么

Binary 工具的 WIDTH 可以输入任意 **1–32 位整数**，例如课程常用的 4、5、10、12 位。所有位宽支持 BIN／DEC／HEX、补码、有符号／无符号解释及加减法的进位、借位、溢出提示。保留 8／16／32 位快捷选择。

缩小位宽保留低位，数值改变时显示橙色提示；有符号扩宽补符号位，无符号扩宽补零。5 位十六进制范围为 00–1F，20 会报错；HEX 是原始位图，即使处于 signed 模式也不是输入十六进制负号。二进制每4位分组，最左边一组可以不足4位。1位有符号数只有 -1 和0，1位无符号数为0和1。

## 2. 哪些检查通过

电脑与实际 SuperH 代码的计算器模拟器均通过 **97,433 项数值共享检查**，含所有1–32位的边界与补码，以及课程4/5/10/12位的直接例题。独立主机算术检查通过 **5,941,888 项**：1–8位全部A/B配对、加减法、两种符号模式；9–32位抽样。

模拟器完成22张新增操作页面、6项交互关系；旧数值51张、布尔59张、单触发器53张、M5工程99张参考页面保持一致，M6的93张页面流程及19项交互检查通过。正式程序及目标测试程序从源码成功构建。

尚未验证本次新增功能在真实计算器上的按键、速度、安装、退出和长期稳定性。模拟器通过不代表实机验收通过。

## 4. 逐步测试

数字直接按，不需要ALPHA。EXE是确认；AC清空当前输入；UP／DOWN选择A或B；F5在输入和结果页面切换。每组测试可先OPTN、1恢复8位无符号255+1，便于从相同起点操作。

1. 首页按 **2、EXE**：默认255+1应得到0，Carry=1。
2. 按 **F4**：出现位宽窗口，Current为8。按 **EXIT**：应返回刚才完整结果，没有修改。
3. 再按 **F4、0、EXE**：出现红色1–32范围提示，不能生效。按 **AC、3、3、EXE**也应报错。按EXIT返回，原结果仍保留。
4. 按 **F4、5、EXE**：回到输入页，顶部为5-bit，A=31、B=1，有橙色位宽缩小提示。原255只保留最低5位，变成31。
5. 按 **EXE**：结果DEC=0、HEX=00、BIN=0 0000，Carry=1，Signed overflow=0。
6. 按 **F5、AC、3、1、DOWN、AC、1、EXE**：确认31+1依然得到0、Carry=1。按F5、AC、3、2、EXE：B=32应标红，不能产生有效结果；它超过5位无符号最大31。
7. 按 **AC、1、5、UP、AC、1、5、F3、EXE**：切换为有符号5位15+15，应得到DEC=-2、HEX=1E、BIN=1 1110，Signed overflow=1，Carry=0。
8. 按 **F1**切到HEX输入页，按 **AC、2、0、EXE**：20超出5位原始位图，应报错。用AC、0修复后才能切换其他设置。
9. 按 **OPTN、8、F4、4、EXE**：加载-5并改为4位，A应仍为-5；A的BIN应为1011，HEX为B，没有数值被截断的提示。
10. 按 **F4、1、0、EXE、AC、NEG、2、8、1**：输入10位-281（NEG是计算器的负号键），A转换应显示BIN=10 1110 0111。也可输入478得到01 1101 1110，输入-2得到11 1111 1110。
11. 按 **F4、1、2、EXE、AC、NEG、6、3**：12位-63的BIN应为1111 1100 0001。不是-1630。
12. 按 **OPTN、1、F4、1、EXE、EXE**：1位无符号1+1得到0、Carry=1；顶部为1-bit。再F3、EXE：相同位图现在解释成-1+-1，结果0、Signed overflow=1。
13. 按 **F4、3、1、EXE**：31位有符号扩宽后A、B都应为-1，二进制全1。按F4、F3直接选32位，A、B仍为-1，按EXE结果-2。
14. 按 **F4、F1**选8位；按F4、F2选16位；按F4、F3选32位，顶部应对应改变。此处F1/F2/F3只在位宽窗口中表示快捷位宽。
15. 按 **F4、5、EXE、EXE**；按EXIT回首页，再按2，应该保留5位设置和刚才结果。EXIT回首页，再EXIT退出计算器程序。

如果任一操作数已标红，先用AC重新输入合法数值，再改进制、符号或位宽；这是原有的输入保护方式。缩小位宽会失去高位，取消窗口不会。再次扩宽不能找回已经丢弃的高位。

## 5. 通过标准

- 可设置1、4、5、10、12、31、32位，0和33不能生效。
- 8／16／32快捷选择、取消和工具返回均正常。
- 上述进位、溢出、补码及非整4位HEX边界结果一致。
- 非法输入不能显示为正常计算结果；缩小位宽改变数值时有提示。
- 原有其他工具仍能打开并正常退出。

## 6. 出错时提供什么

请提供步骤编号、完整数字与按键顺序、当前位宽／进制／符号模式、实际和预期结果、屏幕照片或错误文字，以及重新启动后能否重现。方便时附计算器型号和OS版本。
