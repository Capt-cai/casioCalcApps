## 1. 本阶段实现了什么

ECEN21 Toolkit 目前可以在 fx-CG50 上输入一个简短的函数编码，计算四变量 A、B、C、D 的精确“与或式”（SOP），并显示结果的项数和变量出现次数。支持修改、清空、示例、恒为 0/1 的计算、About 页面及退出。

输入框叫 `ON mask (hex)`，接受 1–4 个字符：0–9、A–F。它是“哪些输入组合的输出为 1”的编码；本次可直接照下面的例子输入，不需要先掌握编码方法。结果中 `'` 表示“非”，连写表示“与”，`+` 表示“或”。`terms` 是相加的项数；`literals` 是变量出现总次数，`A'` 算一次；`16 rows checked` 表示程序已核对四变量的全部 16 种输入组合。

目前不能直接输入 `A+B` 等表达式，也没有真值表、K-map、POS 或 don't-care 的编辑界面。这些不是 M2A 的验收要求。

## 3. 安装与启动：不需要编译

设备：**Casio fx-CG50**、Mac，以及可传输数据的 USB 连接线。

程序文件：[ECEN21.g3a](../.phase1/ecen21/artifacts/ECEN21.g3a)，大小 **72,532 字节**。请只安装这个文件；同目录的 `EC21Test.g3a` 是开发测试程序，不需要安装。

1. 在 Mac 打开 Finder，同时按 **Command + Shift + G**，粘贴下面的文件夹位置，然后按回车：

   ```text
   /Users/maggie/casioCalcApps/.phase1/ecen21/artifacts/
   ```

2. 找到 `ECEN21.g3a`。保留文件名和 `.g3a` 后缀。
3. 打开计算器，用 USB 线连接 Mac。在计算器出现连接模式选择时，选 **F1：USB Flash**。
4. 在 Finder 左侧找到并打开计算器的磁盘，把 `ECEN21.g3a` 复制到**刚打开时的最外层**。不要放进 `@MainMem` 或其他文件夹。
5. 等待复制结束，在 Finder 中点计算器磁盘旁的“推出”，等磁盘消失后再拔线。如果计算器还有结束连接的提示，按屏幕提示完成。
6. 按计算器的 **MENU**，找到 **ECEN21** 图标，用方向键选中后按 **EXE**。预期进入标题为 `ECEN21 Toolkit` 的界面。

把 `.g3a` 文件放在计算器磁盘最外层的方式，依据 [Casio 官方插件安装指南](https://edu.casio.com/content/dam/casio/global/edu-casio-com/download/files/fx-cg50-series/Inst_Users_Guide.pdf)。如果没有出现磁盘、图标或出现错误，请记录卡在哪一步，不需要尝试编译或重置系统。

## 4. 按顺序实测

F1–F6 是屏幕下方的一排功能键。`AC` 指 **AC/ON** 键；不需要按 SHIFT 或 ALPHA。输入字母时按以下实体键：

| 想输入的字母 | 直接按这个键 |
|---|---|
| A | X,θ,T |
| B | log |
| C | ln |
| D | sin |
| E | cos |
| F | tan |

下面每一步都从上一步结束的位置继续；请记录通过或失败。

| 步骤 | 您的操作 | 屏幕应出现的结果 |
|---|---|---|
| 1 启动 | 按上述安装步骤打开程序 | 标题 `ECEN21 Toolkit`，输入框 `007E`，提示按 EXE；此时还未显示计算结果。 |
| 2 示例计算 | 按 **EXE** | `A'C'D+A'BD'+A'B'C`；底部 `3 terms`、`9 literals`、`16 rows checked`。 |
| 3 恒为 0 | 按 **F2**，再按 **EXE** | 输入 `0000`，结果 `0`；底部为 **0 项、0 次变量、16 行已核对**。 |
| 4 恒为 1 | 按 **F3**，再按 **F6** | 输入 `FFFF`，结果 `1`；底部为 **1 项、0 次变量、16 行已核对**。常数 1 计为一项是本程序的约定。 |
| 5 空输入 | 按 **AC**，再按 **EXE** | 提示 `Enter an ON mask first.`（请先输入编码）；不能继续显示上一步的计算结果。 |
| 6 自己输入 | 按 **AC → 7 → cos → EXE** | 输入显示 `7E`，结果和第 2 步相同：**3 项、9 次变量、16 行已核对**。`7E` 与 `007E` 表示同一函数。 |
| 7 删除并重算 | 按 **DEL**，观察后再按 **EXE** | DEL 后输入变成 `7`，旧结果立即清除；EXE 后结果 `A'B'D'+A'B'C'`，底部 **2 项、6 次变量、16 行已核对**。 |
| 8 输入长度限制 | 按 **AC**，按 **tan 四次**，再按 **0**，最后按 **EXE** | 四次 tan 输入 `FFFF`；多按的第五位 `0` 被忽略，输入仍为 `FFFF`；计算结果为 `1`。 |
| 9 长结果 | 按 **AC → 6 → 9 → 9 → 6 → EXE** | 输入 `6996`，结果分行显示；底部 **8 项、32 次变量、16 行已核对**。文字不应被截掉或覆盖底部按钮。 |
| 10 关于与返回 | 按 **OPTN**，再按 **EXE** | 先显示 `About ECEN21`；再回到 `6996` 的计算结果，内容和项数不变。 |
| 11 退出并重开 | 按 **EXIT**，然后在计算器主菜单重新打开 ECEN21 | 应正常回到计算器主菜单；重新打开后回到 `007E` 的初始界面。不保存上次输入是当前预期行为。 |

提示：载入示例或计算完成后，新输入的第一个数字会替换旧输入，并非接在旧输入后面。F2/F3 只载入输入，还需要按 EXE 或 F6 才计算。如果屏幕报错、黑屏或长时间无响应，请停止后续步骤并反馈。

## 5. 如何判断验收通过

- 能安装并进入程序。
- 上述 11 步都与预期一致；结果文字可读，没有缺字、遮挡或异常截断。
- 编辑后不会把旧结果当成新结果；空输入有清楚的提示。
- 没有报错、黑屏或卡住；能正常退出并重新打开。

若有任何一项失败，请先反馈该问题，M2A 保持“待验收/待修复”。尚未实现的表达式编辑、真值表和 K-map 不属于本轮失败项。您不需要重复运行开发者测试工具。
