## 1. 本阶段能做什么

新增首页第7项 Verilog code generator：按题型和参数生成可以在电脑使用的Verilog源代码，而不只是查看固定范例。

支持：行为式／结构式全加器、4→2／8→3普通Encoder、D/T/JK触发器、通用移位寄存器、带同步复位的模N计数器、环形计数器。位数可选1–32；模数N可选1–65535，计数器位宽必须足够；环形初始种子用“哪一位为1”指定。

可以选择时钟沿、允许的复位方式／极性等，完整翻页查看代码和端口说明，再导出 `.v` 文本文件。原有工具保留。不包含FPGA烧录、计算器内Verilog编译器或M9综合题自动串联。

重要规则：

- 触发器／寄存器没有假定的开机初值，需要复位、采样或并行加载建立状态。不带复位的T触发器在普通仿真中可能一直为X；X表示未知。
- 移位优先级：复位 > 并行加载 > 右移 > 左移 > 保持。右移从最高位输入serial_left，左移从最低位输入serial_right。
- 普通Encoder只有一个输入为1时，valid才为1；多个输入不代表优先编码。
- 屏幕长行自动折行，导出的文件保留原始完整行。请使用导出文件，不要按屏幕折行重新抄写代码。
- 文件不会覆盖。每种题型可以选00–99共100个编号；文件名冲突时换编号，或在电脑上先改名／删除你不再需要的旧文件。

## 4. 逐步操作、输入与预期结果

数字直接按，不需要ALPHA。常用键：F1设置、F2代码、F3端口说明、F4导出预览、F5题型、F6 BUILD生成。进入导出页后，F6变成SAVE，才会写文件。设置中UP/DOWN选项目，EXE修改；输入窗口EXE确认，EXIT取消。代码页方向键翻页。

题型菜单：1行为式加法器、2结构式加法器、3 Encoder、4 D、5 T、6 JK、7通用移位寄存器、8模N计数器、9环形计数器。菜单0查看帮助，其他非题型键取消。换题型会替换当前Verilog参数和代码；EXIT返回首页则保留当前数据。

### A. 代码生成、翻页和取消

1. 首页按 **7、F6**：默认生成5位行为式加法器。代码中应有 `module ecen21_add_b`、WIDTH=5，以及a、b、cin、sum、cout等端口。
2. 按DOWN进入下一页，UP应返回原页；第一页面按UP应到最后一页，可看到 `assign {cout,sum}` 和 `endmodule`。长行折行正常，不能缺失后半段。
3. 按 **F3**：看到端口含义、Bit0=LSB。这里LSB就是最低位；cin是初始进位，cout是最后进位。
4. 按 **F2、F4**：进入导出预览，默认文件名ECAB00.v、显示字节数。先按EXIT取消，应返回原代码，尚未保存文件。

### B. 真正导出、文件名冲突和自定义位数

5. 再按 **F4、F6**：若编号00尚未被使用，应出现 **Exported source bytes successfully**。若此前已有ECAB00.v，应出现File exists，这不是计算错误，按下步换一个未使用编号。
6. 按F1，DOWN选Export slot，EXE输入一个尚未使用的编号，例如 **1、EXE**；F4、F6应保存为ECAB01.v。改编号不会改变代码。
7. 测试保护旧文件：记录已保存的一个编号。F1选Width，EXE输入 **1、EXE**，再F2应提示没有当前代码；F6重新生成1位代码。将Export slot改回刚才已使用的编号，再F4、F6，应拒绝覆盖。等会儿在电脑上确认旧文件的WIDTH没有被改成1。
8. 选择另一个空编号保存这份1位代码。F1在Width输入 **0、EXE**、清空后输入 **33、EXE**均应被拒绝；EXIT取消，不应改变原位宽和代码。

### C. 结构式加法器和Encoder

9. 按 **F5、2、F6**：结构式文件应包含 `ecen21_fa1` 单位全加器和 `ecen21_add_s` 主模块。翻页应找到 `carry[0]=cin`、逐位实例及 `carry[i+1]`，最后连接cout。F4、F6可以保存ECAS00.v（若冲突，先换编号）。
10. 按 **F5、3、F6、F3**：Encoder说明应明确“仅valid=1时使用code，没有优先级”。默认INPUTS=4，导出ECEN00.v。
11. F1选Encoder输入数，EXE切为8。F2应没有旧代码；F6生成后应看到INPUTS=8，输出宽度对应3位。选择新编号导出。电脑自动测试已检查全部256种输入。

### D. D/T/JK时钟和复位

12. 按 **F5、4、F6、F3**：默认D触发器为rising、SYNC、high，输出q没有假定开机值。生成的模块名应为ecen21_dff。
13. F1默认第一项Clock按EXE改falling；DOWN到Reset，EXE改ASYNC；DOWN到Reset active，EXE改LOW；DOWN到Reset value，EXE改1。F6、F3应显示 **falling / ASYNC low**。翻代码应找到 `negedge clk`、`negedge rst`、`if (!rst)`，RESET_VALUE为1。
14. 按 **F5、5、F6**：T触发器代码中应有 `q <= q ^ t`；按F5、6、F6查看JK，应有00保持、01清零、10置一、11翻转的case分支。
15. JK设置Reset循环到NONE，再生成；端口说明应显示NONE，rst被忽略，没有额外复位事件条件。不要因为仿真开始为X，就把没有初值的电路当作程序计算错误；要先用确定的JK置位或清零输入建立状态。

### E. 通用移位寄存器

16. 按 **F5、7、F6、F3**：确认优先级为复位、load、右移、左移、保持；右移从MSB端插入，左移从LSB端插入。这里MSB是最高位。
17. F1把Width设为 **1**，F6应成功，不应出现位片段越界错误。代码可导出ECSRxx.v；xx是你选择的编号。电脑仿真已经测试同时请求加载／左右移位的情况。

### F. 模N计数器与环形计数器

18. 按 **F5、8、F6、F3**：默认模12、位宽4、同步复位。代码模块名ecen21_modulo；q达到11后，下一个有效时钟回到0。enable=0保持，复位优先于保持。
19. F1把Width设为 **1**，保留Modulus=12，F6应报位宽不足；F2不应显示旧代码，F4也不能导出旧结果。
20. F1选Modulus，EXE改 **1、EXE、F6**：1位模1应能生成，复位后的计数始终为0。改新编号后保存ECMNxx.v。
21. 按 **F5、9、F6**：默认5位环形计数器，SEED_INDEX=0，即最低位为1。默认向左转；复位后按有效时钟应按00001→00010→00100→01000→10000→00001循环。这些行为已在电脑自动仿真检查。
22. 把Width改为 **1**、Seed bit保留0，再F6应能生成；复位后的唯一一位保持1。若把Seed bit改31，F6应拒绝，因为1位寄存器没有第31位；改回0后应恢复。
23. 也可设置Width=8、Seed bit=2、Rotate=RIGHT、falling、ASYNC、LOW：端口页应显示所选时钟和复位，复位种子为00000100；新编号导出后文件名为ECRGxx.v。

### G. 帮助、返回与USB读取

24. 在代码非第一页，按 **OPTN、0**看帮助，再任意键返回，应保留页面；菜单按EXIT取消也应保留。EXIT回首页，再7，应保留题型、参数和代码。进入原Binary或Combinational后再回来，也应保留。
25. 若在导出预览，先EXIT回代码页；再EXIT回首页、EXIT回计算器主菜单。USB连接并选USB Flash，在Mac上应能找到你导出的 `.v` 文件，文件名和编号与导出页一致。将它们复制到电脑；可以用普通文本编辑器打开，不需要你编译。
26. 检查文件内模块名、WIDTH／INPUTS／MODULUS等默认参数是否与你保存时一致；文件应有完整 `endmodule`，不应含错误消息或屏幕页码。第7步的旧文件应保持原值，未被后来的1位设置覆盖。
27. 安全弹出，重新打开程序。原有布尔、Binary、单触发器、组合逻辑入口应仍能打开；M5/M6专项实机检查继续暂缓，不把本次打开入口视为那些阶段验收通过。

## 5. 如何判定本阶段通过

- 九种题型都能按参数生成完整代码，所有代码页可访问。
- 修改参数后旧代码失效；位宽不足、种子越界等有明确错误且能修复。
- `.v` 文件确实出现在计算器磁盘中，内容与参数对应，文件冲突不会覆盖旧文件。
- 帮助、取消、工具切换保留当前题，程序可以正常退出。
- 上述步骤没有崩溃、卡死或关键文字遮挡。真实磁盘写满不要求你故意制造；若自然遇到错误，请记录原文。
