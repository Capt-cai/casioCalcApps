# M6 时序模拟及 M5/M6 后续统一实机验收指南

你已明确要求“开始M6吧 实机验收后面一起做”。因此，M5、M6 的实机验收都延期，**没有被标记为通过**；M4 仍是已验收并关闭的稳定版本。本指南供你之后统一测试，当前不要求马上连接或安装计算器。M7 尚未批准。

## 1. 本阶段提供什么

新增可编辑的理想数字时序模拟器：D/T/JK/SR 边沿触发器、D/SR 电平 Latch、正／负沿、主从结构、相连触发器、同步／异步复位和初始 0/1/X。可以查看波形、精确数值表、每个器件为什么改变，以及同一个输入事件内部的逐次更新。

范围：4 个外部输入 I0–I3、4 个状态输出 Q0–Q3、4 个逻辑门 G0–G3（NOT/AND/OR/XOR/NAND）、最多 64 次外部事件；加初始状态共 65 列。每次事件最多尝试 32 次内部稳定更新，不稳定会报错。所有器件连接、初始状态、门和事件都能修改，不只是查看固定例子。M3、M4、M5 的计算和页面保持不变。

重要假设：

- 一列代表一次输入事件；第 0 列是初始化后的状态，不是凭空出现的时钟沿。横向宽度用于阅读，不表示真实时间或传播延迟。需要等间隔逻辑刻度时，可添加“保持”事件补列。
- 同一事件中，外部输入先同时更新，触发器再同时采样旧状态。如果希望 D 提前稳定，应将 D 变化放在时钟之前的事件。
- Latch 在允许的电平期间跟随输入；FF 只在选定边沿采样。主从示例是真正的两个 Latch。
- FF 同步复位只在有效沿生效；Latch 的同步复位由透明使能电平限定。异步复位可在时钟沿之间生效，并优先于该器件的正常输入。
- X 是无法确定的逻辑值，不是 0 或 1；未启用的行标为 off／减号或灰色虚线。M6 可以传播 X，再由确定的置位、复位或采样恢复；它不是 M4 单触发器工具的非法状态锁定模式。
- 这是理想三值模型，不模拟真实器件延迟、亚稳态或物理竞争。时钟沿不确定时，会明确说明“可能的边沿”，不会声称已确定采样或复位。

## 2. 自动检查与实机验证的区别

通过的工程检查：时序核心 15,247 项、实际产品示例 381 项，均在电脑和模拟器中的真实计算器代码上运行；八组报告与主机完全一致。独立示例检查覆盖 Review Timing Diagram 1–5 的状态、极性、位序及内部阶段，而不是只检查截图是否存在。

实际按键脚本覆盖 93 张 M6 页面、19 项交互关系；旧布尔、数值、单触发器和 M5 页面与既有版本一致。M5 主机大范围检查、数值检查、布尔化简回归和模拟器基础检查也通过。最大 64 事件／65 列案例有单独的目标运行检查。

这些不代表实机验收。真实按键、屏幕可读性、USB 安装、退出、长时间稳定性和物理速度／内存峰值都仍待之后测试。M5/M6 的验收按你的要求保留为延期状态。

## 4. 后续实机逐步检查

请从刚启动的首页开始。数字直接按，不需要 ALPHA。每次选择新示例都会明确替换当前时序题。

常用键：F1 设置；F2 输入事件表；F3 波形；F4 数值表；F5 事件解释（在事件编辑页则是追加事件）；F6 运行。波形中左右键移动事件列，上下键选择信号。EXE 先看事件解释，再 EXE 看内部更新点；此时上下键选择更新点，F3 返回波形。OPTN 选择示例，OPTN 后 EXE 查看帮助，其他非数字键取消选例。

波形一次显示 4 个信号、8 列；信号名字固定在左边。左／右继续移动可以翻到下一页，页码和 < > 表示还有内容。第 0 列为初始化；关闭的信号不是电路中的实际输出，显示 off／灰色虚线或减号。

事件解释里 `I0^` 表示来自 I0 的上升沿，`I0v` 是下降沿；`I0H`／`I0L` 表示 Latch 在高／低电平透明。I0:0>1 表示该输入从 0 变为 1。内部更新点第 1 点表示外部输入已更新、器件还未提交新状态。

### A. Review Timing Diagram 1：主从 Latch

1. 首页按 **5、F6**。应看到 Review1: master/slave。Q0 是主 Latch，Q1 是从 Latch，初始都为 0；Q2/Q3 未启用。
2. 按 **RIGHT 两次**到 Col2。此时 I0 时钟为高，D 变为 1，应有 **Q0=1、Q1=0**：主跟随了输入，从仍保持。按 EXE 看解释，Q0 应为 Transparent，Q1 为 Hold。
3. 再按 **EXE** 看内部更新点；第 1 点是 Q0=0、Q1=0，按 DOWN 后应为 Q0=1、Q1=0。这是更新过程，不是另一拍时钟。
4. 按 **F3、RIGHT**到 Col3，时钟下降后从 Latch 应变为 Q1=1。按 F5，Q1 的触发标记应为低电平 Latch（L），不是下降沿 FF（v）。
5. 在波形页，若选中 Q0，按 UP 可看到 I0–I3 输入组；再 DOWN 回到 Q 组。选中 Q0 后 DOWN 四次可看 G 组，G0 是 Q1 的取反。F4 应显示与波形一致的精确数值。

### B. Review Timing Diagram 2：Latch、正沿和负沿对比

6. 按 **OPTN、2、F6**。Q0 是高电平 D Latch，Q1 是正沿 D FF，Q2 是负沿 D FF；I0=Clock，I1=D。
7. RIGHT 两次到 Col2，再 F5。应看到 Q0=1、Q1=1、Q2=0；Q0 原因为 Transparent，Q1 为 Capture D，Q2 为 Hold。
8. 再 RIGHT 四次到 Col6：第一次下降沿采样 D=0，Q2 仍为 0，但解释应显示 Capture D。再 RIGHT 五次到 Col11：第二次上升沿应使 Q1=0。再 RIGHT 四次到 Col15：第二次下降沿应使 **Q2=1**，此时 Q0=1、Q1=0。
9. F3 返回波形，F4 看数值；G0、G1、G2 分别是 Q0、Q1、Q2 的取反。输入在时钟高期间变化时，Latch 可以立即改变，两个 FF 不应随每次 D 变化就改变。

### C. Review Timing Diagram 3：级联时钟

10. 按 **OPTN、3、F6、RIGHT、F5、EXE**。第一拍内部应依次显示：Q2Q1Q0 为 **000→001→011→111**，用 DOWN 逐点查看。这里后级时钟来自前级输出，所以必须分阶段更新，不能一次按普通同步计数器处理。
11. F3 看完整波形。8 个上升沿对应的状态，以 Q2Q1Q0 为数值，依次为 **7、6、5、4、3、2、1、0**；Review 图按 Q0 在前写作 **111、011、101、001、110、010、100、000**，两者只是位序不同。LEFT/RIGHT 可访问最后一列，F4 的最终状态应为 000。

### D. Review Timing Diagram 4：四级同步 T

12. 按 **OPTN、4、F6**。初始 Q0、Q1、Q2、Q3 应为 **1、1、1、0**（通常最高位在前的数值是 7）。RIGHT 一次、F5 后，应同时成为 **0、0、0、1**（数值 8），说明所有器件读取了同一份旧状态。
13. F3 后 LEFT 到 Col0，再 LEFT 绕到最后的 Col32；应回到 **1、1、1、0**，页码为 5/5。G0 是 T2=Q0 AND Q1，G1 是 T3=Q0 AND Q1 AND Q2；Q0 本身也作为 T1。通过上下键可查看这些中间信号。

### E. Review Timing Diagram 5：同步反馈复位

14. 按 **OPTN、5、F6**，RIGHT 九次到 Col9，再 F5。状态应为 Q2Q1Q0=101（数值 5），G1 反馈复位已经为 0，但**不能立即清零**。
15. RIGHT 两次到 Col11。此时遇到下一次上升沿，应全部清为 0，三行原因都显示 Sync reset；最终 G1 已回到 1。
16. EXE 查看内部更新点：第 1 点仍为 Q2Q1Q0=101、G1=0；DOWN 后为 000、G1=1。说明复位采样的是清零前的条件。Review 明确写的是 soft／同步复位，符号上的小圆圈只表示低电平有效，不会自动变成异步复位。

### F. 同步／异步与自定义 JK

17. 按 **OPTN、6、F6**，RIGHT 三次到 Col3，再 F5。D 恒为 1，复位在时钟沿之间到来：**Q0 同步器件仍为 1，Q1 异步器件已为 0**；Q1 原因为 Async reset。
18. RIGHT 一次到 Col4：有效边沿到来后，Q0 也成为 0，原因为 Sync reset。若想检查自定义参数，F1、RIGHT 选 Q0，DOWN 八次到 Reset mode，EXE 将 SYNC 改为 ASYNC；F3 应显示没有当前结果，F6 重算，再 RIGHT 三次到 Col3，两者都应为 0。
19. 按 **OPTN、0、F6、F1、RIGHT、DOWN**，选 Q0 的 Type。从 T FF 开始，按 EXE 五次应变为 JK FF；再 DOWN 三次到 Input B，EXE 一次将常量 0 改为常量 1。Input A 已是 1，所以 J=K=1。F6 重算，应与原 T 的翻转一致；第一、第二个上升沿 Q0 分别为 1、0，解释是 Toggle。

### G. X、SR Latch 和错误恢复

20. 按 **OPTN、7、F6**。RIGHT 五次到 Col5：SR 的 S=R=1，Q0 应出现红色未知波形 X；同一拍的 D 器件 Q1 应为 1，因为它采样的是 SR 改变前的旧值。
21. 再 RIGHT 三次到 Col8，F5：Q0 已由确定的清零恢复为 0，而 Q1 采样了先前的 X，故为 X。再 RIGHT 三次到 Col11，两者都恢复为 0。不能将 X 当作 0，也不能永远无法从确定的清零／采样恢复。
22. 按 **OPTN、8、F6**，这是电平敏感 SR Latch。Col2 应置位为 1，Col3 在使能仍高时因 11 立即成为 X，Col4 的确定复位应恢复为 0，Col8 再置位为 1。它不需要每次都等新的时钟边沿。
23. 按 **OPTN、2、F1、RIGHT 两次、DOWN 两次、EXE 两次**，将 Q1 初始值从 0 改为 X。F6 后第 0 列应为 X，直到 Col2 的确定上升沿采样后成为 1。不能在初始化时凭空制造采样。
24. 按 **OPTN、9、F6**，应出现 No stable state within 32 settling phases。任意键返回后按 F3，不得显示旧波形；再 OPTN、1、F6 应恢复正常。程序应报错退出计算，不应卡死。

### H. 手动事件、64 次上限及工具保留

25. 按 **OPTN、1、F2**。第一行原本只改变 I0。RIGHT 选 I1，按 1，使第一行同时将 Clock、D 置为 1。F3 应显示 No current simulation；F6 后 Col1 应为 Q0=1、Q1=0。这验证了“同批输入先更新再采样”的约定。
26. 事件表中，0／1 设置选中输入，2 或循环到点号表示保持；F5 追加一个全保持事件，DEL 删除选中事件，AC 清空。编辑后必须 F6 重算；仅翻页不能偷偷改数据。
27. 按 **OPTN、0、F6、LEFT** 到 Col64，页码 9/9，四个 Q 应全部为 0。F2、F5 尝试追加第 65 次，应明确拒绝并保留 64 次数据；UP 可看到末页第 61–64 次。删除后结果失效；AC 清空再 F6，应只剩初始 Col0，仍能显示合法初始化结果。
28. 回到 **OPTN、1、F6**，移动到第二时间页。EXIT 回首页，依次打开旧布尔、数值、单 FF 和 M5 工具，再回第 5 项，时序题、光标及页面应保留。OPTN、EXE 看帮助，再任意键返回；OPTN、EXIT 取消选例，均不能丢题。
29. 工具内 EXIT 回首页，首页再 EXIT 回计算器系统；重新启动会回到全新默认状态，不承诺把题目永久保存。
