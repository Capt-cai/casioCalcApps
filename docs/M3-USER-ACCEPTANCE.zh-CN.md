# M3 实机验收指南：二进制与有符号数

> 历史指南：原M3后来已获用户验收。本次新增1–32位自定义功能请使用 [新版指南](M3-CUSTOM-WIDTH.zh-CN.md)；当前F4打开位宽窗口，不再直接循环。下文保留当时范围与证据。

M3 已完成开发和工程验证，**等待您的验收；M4 尚未批准**。下面可以直接照做，不需要编译、Git 或测试工具。M2A、M2B 旧版和证据仍保留。

## 1. 本阶段实现了什么

- 新增工具入口：布尔工具和数值工具可来回切换，保留本次运行中的数据。
- 数值工具支持 8/16/32 位，十进制 DEC、十六进制 HEX、二进制 BIN，以及有符号／无符号解释。
- 支持两个数 A、B 的加减法、补码负数、进位、借位及有符号溢出提示。
- 改变位宽时按模式补零或补符号位；缩短位宽导致数值变化会提示。
- 无效数字、空输入、超范围输入会报错，并清除旧计算结果。

现有布尔表达式、真值表、K-map、SOP/POS 和 X 功能保留。**重要变化：工具内 EXIT 先回工具入口，再按 EXIT 才退出到计算器系统。** 关闭程序后不保存数据。

本阶段不含 64 位、八进制、乘除法、移位、触发器、计数器、时序图或 Verilog。

## 4. 如何逐步测试

### 操作说明

入口按 **1/F1** 打开布尔工具，**2/F2** 打开数值工具，也可用上下键选择再 EXE。以下“数字1–8”指数字键，不是 F1–F8。

数值页按键：

| 按键 | 作用 |
|---|---|
| UP/DOWN | 选择 A 或 B，回到输入页；蓝边框表示选中项 |
| 数字键 | 在选中项末尾追加数字；要重新输入请先 AC |
| X,θ,T/log/ln/sin/cos/tan | 输入 HEX 的 A/B/C/D/E/F，无需 ALPHA |
| AC / DEL | 清空选中项／删除最后一个字符 |
| (-) | 输入负号，仅在 SIGNED 的 DEC 输入开头有效 |
| F1 BASE | DEC→HEX→BIN→DEC，保留当前位模式 |
| F2 +/- | 切换 A+B 与 A-B |
| F3 SIGN | 切换 SIGNED（有符号）／UNSIGNED（无符号） |
| F4 WIDTH | 8→16→32→8 位 |
| F5 RESULT/EDIT | 切换结果页／输入页 |
| EXE 或 F6 CALC | 计算 |
| OPTN | 样例菜单，按数字1–8加载；其他键原样返回 |
| EXIT | 返回工具入口；入口 EXIT 退出程序 |

输入需符合顶部显示的进制，不用写 `0x` 或 `0b`。BIN/HEX 输入是原始位模式；SIGNED 主要改变十进制含义。**A、B 都有效才能改进制、符号或位宽**；有错误时先修复，或通过 OPTN 样例恢复有效数据。

Carry 是加法进位，Borrow 是减法借位，Signed overflow 是有符号溢出，`N/A` 表示该操作不适用。进位和有符号溢出不是同一件事。`Wrapped result` 表示真实计算超出了当前模式范围，只保留指定数量的低位；不是数学结果真的变成了显示的回绕值。

### A. 先验证入口和旧工具

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| A1 | 启动后按1，再 EXE | 布尔 SOP `C+AB`，2项、3次变量、16行已核对。 |
| A2 | F2，在第0行 EXE两次，F6→F4 | 第0行是X，结果顶部 MANUAL，核对15行。 |
| A3 | EXIT→2→EXE | 回入口后进入数值工具；默认255+1得到0，Carry=1。 |
| A4 | EXIT→1 | 回到刚才布尔结果：MANUAL、15行、手动X仍保留。 |
| A5 | EXIT→2 | 回到刚才数值结果0，Carry=1。两种工具的数据不会互相覆盖。 |

### B. 验证八个数值样例

在数值工具中，对每行分别按 **OPTN→表中数字→EXE**。样例只是载入数据，EXE 才实际计算。

| 数字 | 设置／计算 | 预期 DEC／HEX | 关键提示 |
|---|---|---|---|
|1|8位 UNSIGNED：255+1|0／00|Carry=1，Borrow=N/A，Signed overflow=0；提示回绕。|
|2|8位 SIGNED：127+1|-128／80|Carry=0，Signed overflow=1；提示回绕。|
|3|8位 UNSIGNED：0-1|255／FF|Carry=N/A，Borrow=1，Signed overflow=0；提示回绕。|
|4|8位 SIGNED：-128-1|127／7F|Borrow=0，Signed overflow=1；提示回绕。|
|5|16位 SIGNED：32767+1|-32768／8000|Signed overflow=1。|
|6|32位 UNSIGNED：4294967295+1|0／00000000|Carry=1，Signed overflow=0；完整显示32位二进制。|
|7|32位 SIGNED：2147483647+1|-2147483648／80000000|Signed overflow=1。|
|8|8位 SIGNED：-5+0|-5／FB|BIN是1111 1011；Carry=0、Signed overflow=0，结果在范围内。|

### C. 自己输入、转换和错误处理

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| C1 手输两数 | OPTN→1；AC→1→2；DOWN→AC→3；EXE | A=12、B=3，相加得到15／0F，无进位或溢出。 |
| C2 切减法 | F2→EXE | 12-3=9／09，Borrow=0，Signed overflow=0。 |
| C3 进制来回转换 | F1三次，再 EXE | 依次HEX、BIN、DEC；仍为12-3=9，不改变数字位模式。 |
| C4 补码解释 | OPTN→8，F1三次 | 依次能看到FB、11111011，再回到-5；下方转换结果一直一致。 |
| C5 同位模式换解释 | 接上步 F3 | UNSIGNED 显示251；HEX仍FB，BIN仍1111 1011。更换设置后原算术结果失效，需重算。 |
| C6 空输入 | OPTN→1→AC→EXE | 报缺少／需修复输入，不显示旧算术结果。 |
| C7 超范围及修复 | OPTN→1→AC→2→5→6；F5看结果，再F5→DEL→EXE | 256超出8位无符号范围；结果页无旧答案。删除末尾6后，25+1=26。 |
| C8 无效二进制 | OPTN→1→F1→F1→AC→2 | 顶部BIN，输入2报无效数字。再按F1也不能悄悄切换进制解释它。 |
| C9 修复二进制 | 接上步 DEL→1→EXE | A=1、B=1，结果2，BIN0000 0010。 |

### D. 位宽变化和退出

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| D1 符号扩展 | OPTN→8→F1，再F4、F4、F4 | 从8位HEX FB，变为16位FFFB、32位FFFFFFFB，再回8位FB；十进制始终-5，没有数值截断提示。 |
| D2 补零扩展 | 接上步 F3→F4 | 变为16位UNSIGNED；A=00FB，十进制251。 |
| D3 缩位提示 | 接上步 F3→F4→F4→EXE | 16位SIGNED的251扩到32位，再缩8位成为-5；显示橙色 `Width reduction changed an operand value.`，计算后提示仍在。当前-5+0可以“符合SIGNED范围”，与先前缩位丢信息是两回事。 |
| D4 菜单返回 | OPTN→EXE | 不加载样例，原结果保留。 |
| D5 退出重开 | EXIT回入口，再EXIT；从计算器主菜单重开 | 能正常退出；重开回工具入口。重新进入数值工具恢复默认255、1，不保存上次运行数据。 |

可选32位手输边界：OPTN→7，AC 后用(-)键和数字输入 `-2147483648`，F2切减法，EXE。预期结果2147483647／7FFFFFFF，Borrow=0、Signed overflow=1。

## 5. 怎样算通过

所有必测步骤与预期一致；进位／借位／溢出没有混淆；转换不偷偷改变位模式；有错误时不显示旧算术结果；缩位信息损失有提示；布尔数据在工具切换后保留；没有遮挡、卡死或异常退出，并能正常返回系统，即满足本轮验收目标。若某一步失败，先反馈，M3 保持待验收／待修复。未实现的乘除、移位或时序工具不属于失败项。
