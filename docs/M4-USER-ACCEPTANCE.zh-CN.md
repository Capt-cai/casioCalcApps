# M4 用户实机验收指南：触发器工具箱

状态更新：你已明确确认 M4 通过真实 Casio fx-CG50 实机验收，并正式批准关闭 M4。M5 尚未批准。本指南保留为安装与测试参考；验收来自你的确认，不表示我们替你操作过实体计算器，也不包含未提供的性能或内存测量。

## 1. 本阶段提供什么

新增 SR、D、JK、T 四种单个触发器工具：特性表（给出输入后求下一状态）、激励表（希望状态改变时应给什么输入）、一次推进一步的模拟、最多 16 步的记录。原来的布尔工具、8/16/32 位二进制与补码工具保留。

Q 是当前保存的 0 或 1；Q+ 是执行下一步后的状态。RISE 是上升沿，FALL 是下降沿，NONE 是没有时钟事件。只有事件与选定的 Active 边沿相同才采样输入。表里的 X 表示“输入用 0 或 1 都可以”，不是当前 Q 未知。感叹号 ! 表示下一状态未定义。

SR 采用同步、高电平有效的规则，不是无时钟的 SR 锁存器。SR 的两个输入都为 1 且遇到有效时钟时，程序显示未定义并阻止继续模拟，要求重新初始化。本阶段不含计数器、多触发器连接、波形图、异步置位/复位、电气时序分析或 Verilog。

## 2. 已验证什么，什么仍需你确认

- 电脑自动检查和以计算器代码运行的模拟器检查均通过：新增触发器 3,849 项，原有布尔模型 6,516 项、数值模型 20,779 项、早期控制器 218 项。
- 触发器检查包括全部 192 种状态/输入/时钟组合、24 行特性表、16 种激励查询，以及 X 的所有取值、非法状态恢复和记录上限。
- 另通过数值运算 2,359,296 项检查、布尔化简 153,092 个算例、模拟器基础检查 5/5。
- 模拟器生成 54 张触发器操作截图，并检查 22 项页面关系；原有布尔 59 张页面和数值脚本中 51 张工具页面与已验收版本完全一致。主菜单增加第三项，外观有意变化。
- 这些不是实机测试。实体按键、屏幕可读性、返回计算器系统、USB 安装、长时间稳定性和实际运行速度仍需实机确认；未测量实机内存峰值。

## 4. 逐步测试

请从刚启动程序的主菜单开始，按顺序操作。数字键直接按，不用 ALPHA。每处“按 EXE”都指按一次，除非明确写了次数。

常用键：F1 TYPE 换类型；F2 VIEW 依次切换模拟、特性表、激励表、记录；F3 EDGE 换有效边沿；F4 RESET 后按 0/1 重新设置初始 Q；F5 EVENT 依次 RISE→FALL→NONE→RISE；F6 或 EXE 在模拟页执行一步。换类型会清空记录、恢复初始 Q、输入归零并把事件设为 RISE，但保留有效边沿。F4 重置保留输入、事件和边沿，请检查屏幕再执行。

### A. D 触发器和时钟（步骤 1—8）

1. 主菜单按 **3**。应为 D、Active: RISE、Current Q: 0、Steps: 0/16，D 输入为 0，事件 RISE。
2. 按 **1**。D 应变为 1，Next preview 显示 Q+=1，但 Current Q 仍为 0，步数仍为 0。预览不等于已经执行。
3. 按 **F5、EXE**。事件为 FALL，当前 Q 仍为 0，步数 1/16，Last step 显示 Hold。
4. 按 **F5、EXE**。事件为 NONE，Q 仍为 0，步数 2/16。
5. 按 **F5、EXE**。事件回到 RISE，Q 变为 1，步数 3/16，显示 Capture D。
6. 按 **F3、1、F5、EXE**。Active 改为 FALL，D 改为 0，事件 FALL，Q 应变为 0，步数 4/16。
7. 按 **F4、1**。Q 应成为 1，步数清为 0/16；D=0、Active=FALL、事件 FALL 均保留。再按 **F4、EXIT**，应取消重置，页面和数据不变。
8. 按 **F3、F5、F5**。恢复 Active=RISE、事件 RISE。连续按 F2：依次看到 D 特性表 4 行、激励表 4 行、空记录，再一次 F2 回模拟。特性表 D=0 时 Q+=0，D=1 时 Q+=1；激励表要求 D 等于目标 Q+。

### B. JK 和 T（步骤 9—13）

9. 从 D 模拟页按 **F1、F4、0**。应切换到 JK，Q=0，输入 J=K=0，步数 0。按 **1、2**，J、K 应都为 1。
10. 按 **EXE**，Q=1、步数 1；再按 **EXE**，Q=0、步数 2。两次都显示 Toggle。
11. 按 **F2** 看 JK 特性表（8 行）；再按 **F2** 看激励表（4 行）。其中 Q 从 1 变为 0 的一行必须为 **J=X、K=1**。再按 F2 看两条 Toggle 记录，再按 F2 回模拟。
12. 按 **F1** 换 T。按 **1、EXE** 得 Q=1；按 **1、EXE** 得 Q=1、Hold；按 **1、EXE** 得 Q=0、Toggle。累计三步为 **1、1、0**。
13. 按 F2 查看 T 特性表（4 行），再 F2 查看激励表：不改变状态要求 T=0，改变状态要求 T=1。再 F2 查看刚才三步记录，再 F2 回模拟。

### C. SR 非法输入与恢复（步骤 14—19）

14. 按 **F1** 换 SR。应为初始 Q=0、S=R=0、Active=RISE、事件 RISE。按 **1、EXE**：S=1、R=0，Q 应变为 1，显示 Set。
15. 按 **1、2、EXE**：S=0、R=1，Q 应变为 0，显示 Reset。
16. 按 **1**，S=R=1。预览应显示 INVALID，但尚未执行。按 **F5、EXE**，事件 FALL 时 Q 仍为 0；按 **F5、EXE**，事件 NONE 时 Q 仍为 0。这是同步模型中没有采样输入的情况。
17. 按 **F5、EXE**。事件回到 RISE，必须显示红色 `Current Q: undefined`，Last step: INVALID，步数为 5/16。不能给出可继续使用的二进制下一状态。
18. 按 **1、EXE**：虽然 S 已修复为 0，也仍不能继续；Q 保持显示 undefined，步数仍 5/16，并要求重新初始化。按 F2 看 SR 特性表，S=R=1 的两行应显示红色 !；再 F2 看激励表；再 F2 看记录，第 5 步为红色 !/Invalid；再 F2 回模拟。
19. 按 **F4、0、EXE**。重新初始化保留 S=0、R=1，执行后 Q=0、步数 1/16，错误消失，模拟恢复。

### D. 记录上限、工具切换与退出（步骤 20—25）

20. 按 **F4、0、2**。现在应为 SR、Q=0、S=R=0、事件 RISE、步数 0。按 EXE **16 次**。应一直 Q=0，最后 Steps: 16/16。第 **17 次** EXE 应显示 `History full`；步数仍为 16，不得覆盖旧记录。
21. 按 **F2 三次**进入记录，看到第 1 页（Page 1/3）。按 **UP** 应到第 3 页，可见第 15、16 步；再按 **UP 两次**到第 2 页，可见第 8—14 步。R/R 表示当时有效边沿和事件都为上升沿；R/F 表示有效上升沿但事件为下降沿；减号表示没有事件。
22. 按 **F2** 回模拟，记住 Q、输入、步数和提示。按 **EXIT、1** 进入布尔工具，按 EXE 应能得到布尔结果；按 **EXIT、2、EXE** 进入数值工具，首次进入默认 255+1 应为 0、Carry=1。按 **EXIT、3**，触发器工具的 Q、输入、16 步记录及满记录提示应保持。
23. 按 **OPTN** 看帮助，再按 **EXE** 返回，数据应不变。按 **F4、0** 清空，随后 EXE 应重新正常记录第 1 步，Q=0，无满记录错误。
24. 按 **F1** 换 D，应重新从初始 Q=0、D=0、事件 RISE、步数 0 开始。按 EXIT 回主菜单；用上下方向键选择第三项，按 EXE，应重新进入触发器工具且数据保留。
25. 按 **EXIT** 回主菜单，再按 **EXIT** 返回计算器系统。重新启动 ECEN21 后，应为全新状态；数据只在本次打开期间保留，不会永久保存。

## 5. 如何判断验收通过

- 四种触发器的指定状态序列正确；有效边沿与无效边沿区分正确，预览不会自己推进。
- 特性表、激励表行数和值正确，X 的说明清楚，SR 非法行用 ! 明确标出。
- SR 非法后不会继续显示可用的当前 Q，修复输入不会绕过锁定，重新初始化后能恢复。
- 第 17 步明确拒绝，不覆盖记录；三个记录页均可访问，记录中的边沿/事件不随后来设置变化。
- 工具切换和帮助不丢数据；换类型和初始化按说明清空；退出可返回系统。
- 原有布尔和数值工具可用，文字无影响阅读的遮挡、缺失，程序不卡死或异常退出。

全部满足后，请回复“M4 验收通过”。若同时希望开展下一阶段，请另外明确批准 M5；验收通过本身不会自动启动 M5。
