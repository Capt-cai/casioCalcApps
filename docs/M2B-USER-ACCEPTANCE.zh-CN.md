## 1. 本阶段实现了什么

- 直接输入 A–D 的布尔表达式，支持括号、与、或、非、异或；输入有误时显示位置。
- 查看并修改真值表，把输出设为 `0`、`1` 或 `X`（不关心：允许求解器自由选择该行的输出）。
- 查看同步的 K-map；在图上也能直接修改同一份输出数据。
- 精确求解 SOP（与或式）和 POS（或与式），显示项数及变量出现总次数。
- 查看每个分组、对应行号和结果项，说明哪些变量固定、哪些可消去。
- 支持 2、3、4 变量及长公式换行。分组说明不是完整的逐条代数证明。

M2B 的输入界面已取代 M2A 的十六进制编码框。旧版文件仍保留在 Mac，可供需要时改回。二进制运算、触发器、计数器、时序图、Verilog 不在本阶段。

## 3. 如何安装新版

新版文件：[ECEN21.g3a](../.phase1/ecen21-m2b/artifacts/ECEN21.g3a)，大小 **80,124 字节**。只复制这个文件，不要安装 `EC21Test.g3a`。

1. Mac 打开 Finder，按 **Command + Shift + G**，粘贴下面的文件夹位置并回车：

   ```text
   /Users/maggie/casioCalcApps/.phase1/ecen21-m2b/artifacts/
   ```

2. 打开计算器，用 USB 数据线连接 Mac，出现连接模式时选择 **F1：USB Flash**。
3. 在 Finder 打开计算器磁盘，把新版 `ECEN21.g3a` 放在最外层，不要放进 `@MainMem`。已有同名 M2A 文件时，用新版替换它。
4. 复制结束后，在 Finder 推出计算器磁盘再拔线，按计算器提示结束连接。
5. 按计算器 **MENU**，选择 **ECEN21** 并按 **EXE**。新版应显示表达式 `AB+C`，不再是旧版的 `007E` 编码框。

此安装方式遵循 [Casio 插件安装指南](https://edu.casio.com/content/dam/casio/global/edu-casio-com/download/files/fx-cg50-series/Inst_Users_Guide.pdf)。旧版仍在 `/Users/maggie/casioCalcApps/.phase1/milestones/M2A/artifacts/ECEN21.g3a`，可用同样方法替换回去。

## 4. 如何逐步测试

### 先认识按键

| 按键 | 作用 |
|---|---|
| F1 / F2 / F3 | 表达式 / 真值表 / K-map；切页本身不改数据 |
| F4 | 进入结果页；**已在结果页时再按 F4** 才切换 SOP/POS |
| F6 | 计算两种形式；在表达式页按 EXE 也能计算 |
| F5 | 看屏幕按钮：表达式页 USE EX、表格页 VARS、结果／图页 GROUP、分组页 KMAP |
| OPTN | 样例／关于菜单；1–6 加载对应样例，其他键原样返回 |
| EXIT | 退出程序 |

表达式页无需 SHIFT／ALPHA：X,θ,T、log、ln、sin 分别输入 A、B、C、D；`+` 输入“或”，`×` 输入“与”，幂键 `^` 输入异或，`÷` 插入前缀 `!`（非），小数点键插入后缀 `'`（非），括号键直接可用。`AB` 也表示 A 与 B。优先级为：非、与、异或、或；括号优先。

左右方向键移动光标，DEL 删除光标前的字符，AC/ON（下文简称 AC）清空。**新输入是在光标处插入，不再采用 M2A“第一个字符替换旧输入”的规则；要重新输入请先 AC。** 最多 79 个字符。

顶部 `EXPR` 表示使用表达式；`MANUAL` 表示使用手动表格。`terms` 在 SOP 中表示乘积项数，在 POS 中表示括号子句数；`literals` 是变量出现总次数；`cared rows checked` 是已核对的非 X 行数。

### 按顺序完成基本验收

| 步骤 | 输入／按键 | 预期看到什么 |
|---|---|---|
| 1 默认表达式 | 打开新版，按 **EXE** | `AB+C` 的 SOP 为 `C+AB`，**2 terms、3 literals、16 cared rows**。 |
| 2 切换 POS | 在结果页按 **F4** | POS 为 `(B+C)*(A+C)`，**2 terms、4 literals、16 cared rows**。 |
| 3 手动修改并同步 | 按 **F2**，第 0 行处按 **EXE 两次**，再按 **F3** | 第 0 行从 0→1→X，顶部变为 MANUAL；K-map 编号 0 的格子也显示 X；旧分组失效，提示重新计算。 |
| 4 计算并保留手动数据 | 按 **F6 → F4** 查看结果，再按 **F4** 切回 SOP；然后 **F1 → F2** | 仍能得到 `C+AB`，但只核对 **15 行**；来回切页后，第 0 行仍为 X，没有被旧表达式覆盖。 |
| 5 明确恢复表达式 | 按 **F1 → F5（USE EX）→ EXE** | 恢复 EXPR，SOP `C+AB`，重新核对 **16 行**。这是主动丢弃手动 X 的操作。 |
| 6 错误提示与修复 | **F1 → AC → X,θ,T → + → F6**，再看 F2/F3；最后 **F1 → log → EXE** | `A+` 报第 **3** 个字符处缺少内容，表格／图不再显示旧数据；补 B 得到 `A+B` 后恢复计算，SOP 为 `B+A`（2 项、2 次变量），核对 16 行。 |
| 7 精确求解反例 | **OPTN → 2 → EXE** | SOP 为 `A'C'D+A'BD'+A'B'C`，**3 项、9 次变量**。在结果页按 F4 查看 POS，应为 **3 子句、7 次变量**。 |
| 8 分组与消去说明 | 再按 F4 回 SOP，按 **F5 → DOWN**，然后 F5 | 分组页显示 **Group 2/3**、`A'BD'`、覆盖行 **4,6**；`C=*` 表示 C 可变，因此结果不含 C。F5 回 K-map，编号 4、6 的格子以橙框表示同一分组；它可跨图左右边缘。蓝框只是编辑光标。 |
| 9 X 如何帮助化简 | **OPTN → 3 → F6 → F4**；再按 F4 看 POS | 两变量表中 row0=X、row1=1，其余为0。SOP 为 `A'`，POS 为 `(A')`，均为 **1 项／子句、1 次变量、3 行已核对**。 |
| 10 在图上编辑同一份数据 | 接上步 POS 页面，按 **F3 → EXE → F6 → F4 → F4** | 编号0由 X 变0；SOP 变成 `A'B`，**1 项、2 次变量、4 行已核对**。可按 F2 确认表格第0行也变0。 |
| 11 变量范围检查 | **OPTN → 1 → F2 → F5 → F1**；随后 **F2 → F5 → F6 → F4** | 第一次从4变量减到2变量，C 不在允许范围，显示第4字符错误；再切到3变量后表达式有效，SOP `C+AB`，核对 **8 行**。 |
| 12 长公式与全部分组 | **OPTN → 4 → EXE**，按 F5，再按 DOWN 七次；F4 进入结果，再按 F4 | SOP 为 **8 项、32 次变量**；分组能到 **Group 8/8**，再按 DOWN 回第1组；POS 也为 **8 子句、32 次变量**，长公式完整换行。 |
| 13 样例菜单不丢数据 | 按 **OPTN → EXE** | 不选样例直接返回，仍是上一步的结果。菜单中的数字1–6会明确替换当前工作。 |
| 14 退出并重开 | 按 **EXIT**，从主菜单重开 ECEN21 | 正常回到计算器主菜单，重开回到 `AB+C`。当前不保存上次输入。 |

注意：表格页 F5 的变量数按 **4→2→3→4** 循环。表达式模式会按新变量数重算，超范围变量会报错；手动模式缩小时只保留低编号行，增加变量时补0。**这不是代数消元，高编号行被丢弃后不会自动恢复。**

### 可选边界检查

- **所有行都是 X：** OPTN→5 加载0；F2→F5 切到2变量。在每一行按EXE两次，按DOWN到下一行，直到四行全X；F6→F4 查看 SOP 为0，再按F4查看 POS 为1，两者核对行数均为0。因为没有任何行要求固定输出，这两个答案都允许。
- **常数：** OPTN→5→EXE 得到0；OPTN→6→EXE 得到1。不同形式的项数可以不同：SOP常数0使用空和，POS常数1使用空积；请以结果正确为准，不把这种表示约定视为错误。
- **括号与非／异或按键：** F1→AC 后输入 `!(A+B)C^D'`（依次按 ÷、左括号、X,θ,T、+、log、右括号、ln、幂键、sin、小数点），EXE 后 SOP 为 `C'D'+BD'+AD'+A'B'CD`，4 项、10 次变量。

## 5. 怎样判断本阶段通过

基本步骤的输入、真值表、K-map 和结果一致；错误输入不会留下看似有效的旧数据；SOP/POS 与 X 行处理正确；能查看全部分组及完整公式；没有遮挡、报错、黑屏或卡死；能退出并重开，即满足本轮用户验收目标。任何一步失败，先反馈并保留“待验收／待修复”。

本阶段不要求逐条代数证明，也不包含二进制、时序或 Verilog 功能。
